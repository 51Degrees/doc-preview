check_usage_sharing_last ( flow_elements)

Refuse FlowElements that put the usage sharing element anywhere but last.

It shares the Evidence the other FlowElements add, so it runs after all of them. A Pipeline here has no parallel groups, so the element is always outside one.

@type flow_elements: sequence of FlowElement

Parameters
