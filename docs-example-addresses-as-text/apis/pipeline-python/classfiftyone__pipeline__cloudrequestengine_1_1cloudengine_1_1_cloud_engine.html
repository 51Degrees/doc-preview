fiftyone_pipeline_cloudrequestengine.cloudengine.CloudEngine Class Reference

Detailed Description

This is a template for all 51Degrees cloud engines.

It requires the 51Degrees cloudRequestEngine to be placed in a pipeline before it. It takes that raw JSON response and parses it to extract the device part. It also uses this data to generate a list of properties.

◆ on_registration()

fiftyone_pipeline_cloudrequestengine.cloudengine.CloudEngine.on_registration ( self,
pipeline )

Callback called when an engine is added to a pipeline In this case sets up the properties list for the element from data in the CloudRequestEngine.

If the CloudRequestEngine could not fetch the accessible properties when it was built, the pipeline is still built and this engine has no properties until that engine fetches them on first use.

The engine may be in several pipelines that share one CloudRequestEngine, as its properties are the same in each. A pipeline with another CloudRequestEngine is refused.

@type pipeline: Pipeline
