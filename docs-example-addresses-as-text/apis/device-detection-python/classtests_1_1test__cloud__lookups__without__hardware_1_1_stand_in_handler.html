tests.test_cloud_lookups_without_hardware.StandInHandler Class Reference

Detailed Description

Answers the accessible properties and evidence keys requests as the cloud service does, with the server's accessible properties, and anything else with 404.

The accessible properties request is answered with the server's failing status instead while it has failures left, and a lookup with the server's lookup answer when it has one. The method and path of each request are kept.
