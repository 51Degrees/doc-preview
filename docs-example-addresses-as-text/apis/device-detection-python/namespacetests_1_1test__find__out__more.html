tests.test_find_out_more Namespace Reference

Detailed Description

Every example ends with a "Find out more" section, which gives the person running it links to follow up, wherever the example ends.

The first checks read the examples' source. The others run each example to an early end, with no resource key or no data file, so none of them needs a key, a data file or the network.
