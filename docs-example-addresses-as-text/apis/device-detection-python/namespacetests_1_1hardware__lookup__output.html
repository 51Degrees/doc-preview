tests.hardware_lookup_output Namespace Reference

Detailed Description

How a test reads what the TAC and native model lookup examples print.

The live tests in test_cloudexamples.py use it, and test_hardware_lookup_output.py tests it without a key.

◆ vendor_and_model()

vendor_and_model ( line)

The vendor and model of a device line, which has the form '<vendor> <name> (<model>)', or None when the line has another form.

The vendor is the text before the first space, and the model the text inside the final parentheses, which may hold parentheses of their own when it has no value and gives the reason.
