tests.test_data_update_product Namespace Reference

Detailed Description

The data file names the Distributor's product for the data file in use, which the data file update service asks for when the license key holds several products.

Once the engine has loaded the data file, the product is the engine's. Before that it is read from the header of the data file at the configured location.
