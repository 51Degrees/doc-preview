enum FiftyOne.DeviceDetection.Example.Tests.Cloud.StandInAnswer

How the stand-in for the cloud service answers.

Enumerator
NoHardware 

As for a resource key that does not include the hardware lookup.

NoDevices 

As for a key that does, where every lookup matches no device.

Failing 

With status 500 to every request, as a service that is failing.

FailsOnceThenNoHardware 

With status 500 to the first request for the key's properties, then as NoHardware.

FailsOnceThenNoDevices 

With status 500 to the first request for the key's properties, then as NoDevices.

RefusesTheKey 

With status 403 to every request for the key's properties, as the service does for a key it refuses.

LookupFails 

As NoDevices for the key's properties, then with status 500 to every lookup.

UnknownProfileProperty 

As NoDevices, with one more profile property whose name and list type the SDK does not know.
