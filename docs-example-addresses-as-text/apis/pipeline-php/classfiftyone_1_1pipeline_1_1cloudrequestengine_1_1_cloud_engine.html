fiftyone\pipeline\cloudrequestengine\CloudEngine Class Reference

Detailed Description

This is a template for all 51Degrees cloud engines.

It requires the 51Degrees cloudRequestEngine to be placed in a pipeline before it. It takes that raw JSON response and parses it to extract the device part. It also uses this data to generate a list of properties. It reads no Evidence, so it accepts none.

See also
https://github.com/51Degrees/specifications/blob/main/pipeline-specification/pipeline-elements/cloud-aspect-engine.md

Log once, at warning level, when the products the Cloud Request Engine found hold nothing for this engine's Data Key.

A Resource Key with no product for the engine is not an error. Call this after reading the Cloud Request Engine's Element Data, because the products are found before that data is set.
