fiftyone.devicedetection.examples.shared.ExampleProcess Class Reference

Detailed Description

Runs an example's main method in a new Java process with no key in its environment, as someone runs it from a fresh clone, for the tests of what an example does with no settings, or with one resource key, as a customer runs it.

A new process is needed because a running Java process cannot remove a variable from its own environment.

◆ runWithoutKeys()

Result fiftyone.devicedetection.examples.shared.ExampleProcess.runWithoutKeys ( Class<?> example) throws Exception
static

Runs the example's main method with no arguments and with every environment variable whose name holds "KEY", in any case, left out.

The process takes the class path of the process that starts it, and of its system properties only _51DEGREES_PROJECT_ROOT, which says where the files the example reads are.
