fiftyone.devicedetection.examples.console.HardwareLookupStandInTest Class Reference

Detailed Description

Runs the TAC and native model examples against a stand-in for the cloud service that this test starts on this machine, so no resource key or network is needed.

The stand-in answers the accessible properties, the evidence keys and the lookup with what each test sets, and anything else with 404, and records the path of every request.
