FiftyOne.DeviceDetection.Example.Tests.Cloud.HardwareLookupWithoutTheLookupTests Class Reference

Detailed Description

Runs each hardware lookup example against a stand-in for the cloud service that answers as it does for a resource key without the hardware lookup.

The example should say so on one line, with links to create a key that includes it and to contact 51Degrees, end without an error and look nothing up. No real key or network is needed.
