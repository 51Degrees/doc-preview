FiftyOne.DeviceDetection.Example.Tests.Web.OnPremise.GettingStartedWebWithoutSettingsTest Class Reference

Detailed Description

Runs the GettingStarted-Web example as someone who has just cloned the repository does, from its own folder with no arguments and none of the settings the other tests are given, and asks it for its page.

So the example uses the free Lite data file that the data repository links, and the test checks that the page is served, shows the properties only the Enterprise data file has as needing it, links to the contact page and ends by saying where to find out more.
