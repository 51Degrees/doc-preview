FiftyOne.DeviceDetection.Example.Tests.Web.CloudExampleFactory< T > Class Template Reference

Detailed Description

The web application factory for a cloud example.

The example reads its resource key from the environment, when its host is built and, for some examples, on each request, so the key from ExampleResourceKey.Name stays in the example's variable until the factory is disposed. Without a key the factory throws, so the tests fail, unless ExampleResourceKey.RunHere is false, when it takes no key and the tests skip with NotRunHere.
