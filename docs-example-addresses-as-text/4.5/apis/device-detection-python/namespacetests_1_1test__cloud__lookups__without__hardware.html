tests.test_cloud_lookups_without_hardware Namespace Reference

Detailed Description

Runs the TAC and native model lookup examples against a stand-in for the cloud service, with a resource key that does not carry the hardware lookup.

Each example must say so in one line, with tagged links to create a key that carries it and to contact us, and end normally without asking for a lookup. When the stand-in fails the accessible properties request instead, each example must end with that failure and never say the key lacks the lookup. When the key carries the lookup and the lookup matches no device, each example must say so under each heading and end normally. When the first accessible properties request fails and the next succeeds, each example must ask again and act on the answer it then gets. The stand-in answers as the cloud service does, so these tests need no key and no network.
