tests.data_update_standin Namespace Reference

Detailed Description

A stand-in for the Distributor on this machine, so a test of the data file update example never reaches the Distributor and needs no real licence key.

It answers as the Distributor does for a licence key that holds several products, whatever key it is sent:

  • a request that names no product gets 300 with the list of products, and a Location header naming the first
  • a request for a product not on the list gets 403
  • a request for a product on the list gets the data file to serve, gzipped and with the MD5 hash of what is sent as lower case hexadecimal, unless the request's If-Modified-Since is not earlier than the file's published date, when it gets 304

Every request is recorded with the product it named and the status it got.
