tests.test_data_update_product.StandIn Class Reference

Detailed Description

Answers as the Distributor does for a licence key that holds the products, whatever key it is sent.

A request that names no product gets 300 and the list of products, a product on the list gets 304, as there is nothing newer, and any other product gets 403. Each request is recorded with the product it named and the status it got.
