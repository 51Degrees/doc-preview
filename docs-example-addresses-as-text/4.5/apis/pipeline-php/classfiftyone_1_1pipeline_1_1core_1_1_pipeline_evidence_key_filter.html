fiftyone\pipeline\core\PipelineEvidenceKeyFilter Class Reference

Detailed Description

The Evidence a Pipeline accepts, being every key that at least one of its FlowElements accepts.

Each element is asked when a key is checked, so the filter follows an element whose accepted Evidence changes.

The Pipeline builds one when it is built. It is a class rather than a closure because an element's data refers to its element, the element to its Pipelines, and a session cache serializes that data, which a closure would stop.
