fiftyone_pipeline_core.elementdata._CheckedDictWrites Class Reference

Detailed Description

The write methods of a dict, each of which calls _check_writable first, so a dict that holds Element Data values refuses writes once the FlowElement that writes them has finished.

Reads are the dict's own.
