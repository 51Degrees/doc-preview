FiftyOne.IpIntelligence.Example.Tests.OnPremise.TestWorkerExitCode Class Reference

Detailed Description

The Metrics and Compare examples run in a hosted worker.

A run that fails must leave the process with a failure exit code, so that a script or a test that runs the example can tell. Each test runs a worker on a file that is not a data file, so building the engine fails, and checks the exit code the process would end with. The tests change the process's exit code, so they put it back and run apart from the others.
