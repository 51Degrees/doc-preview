tests.test_keys_and_property_list.EvidenceKeysTests Class Reference

Detailed Description

The Evidence keys come from the data file, so the engine reads them at start-up and again whenever the data is refreshed.

The engine keeps the evidence key filter it makes from the keys, and makes another only when the keys change, so a request does not make one for each of its Evidence keys.
