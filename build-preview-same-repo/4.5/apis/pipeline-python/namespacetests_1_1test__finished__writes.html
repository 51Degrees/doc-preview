tests.test_finished_writes Namespace Reference

Detailed Description

Every FlowElement this package defines, and every one its examples define, is
processed, then a write to its ElementData is expected to fail, as the thread
safety page of the specification requires.

A FlowData that has finished processing refuses Evidence, ElementData and
errors, and ElementData refuses a write once the FlowElement that writes it
has finished, as the thread safety page of the specification requires. The
last tests process every FlowElement this package defines, and its example
FlowElements, then write to each one's ElementData and expect the error.

The engines package defines only the Engine that other FlowElements build
on. Its example engine is processed, then a write to its ElementData is
expected to fail, as the thread safety page of the specification requires.

Every FlowElement this package defines is processed, as the thread safety
page of the specification requires. The usage sharing element adds no
ElementData, so a finished FlowData holds none for it, and the FlowData
refuses one being added.
