tests.test_datafile_update_http.StartUpCheckErrorTests Class Reference

Detailed Description

An error the errors table does not name, raised in the update on start-up.

data-updates.md line 354 says every check MUST be reported to onUpdateCallbacks once it ends, "including the checks made by update polling, by the file watcher, by the update on start-up and by a programmatic call". Lines 477 to 478 say "A programmatic check, the update on start-up and an update from memory pass the error to their caller instead of logging it", and lines 475 to 476 say a failure "MUST NOT stop later checks for updates".

So the check is reported as AUTO_UPDATE_UNKNOWN_ERROR, the error reaches the caller that registered the data file, nothing is logged, and the next check is still scheduled.
