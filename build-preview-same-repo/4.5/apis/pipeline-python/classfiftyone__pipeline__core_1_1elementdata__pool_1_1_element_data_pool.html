fiftyone_pipeline_core.elementdata_pool.ElementDataPool Class Reference

Detailed Description

A bounded pool of the ElementData one FlowElement makes, so that a request reuses an instance an earlier request has finished with rather than making a new one.

The FlowElement keeps it as _element_data_pool, which FlowElement.get_element_data_pool() returns, and takes from it while it processes. FlowData.close() gives each instance back after closing it.

An instance from the pool has no values and is open for writing, as take() calls its _clear method, which a class with values of its own overrides to drop them. An instance a cache may hold never goes back, because the cache shares it with other requests, and the instances of a FlowData that is not closed are left to the garbage collector.

Requests on several threads share the pool, so it takes a lock of its own. It never locks a FlowData or ElementData.
