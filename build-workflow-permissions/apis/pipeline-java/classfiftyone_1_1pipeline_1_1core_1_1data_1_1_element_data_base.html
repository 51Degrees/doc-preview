fiftyone.pipeline.core.data.ElementDataBase Class Referenceabstract

Detailed Description

Base implementation of ElementData.

Represents property values that have be determined by a specific FlowElement based on the supplied evidence.

An instance is written only by the FlowElement that creates it, while that element processes. It is not intended to be written from several threads at once, nor read while it is being written.

See also
Specification
Thread safety

Element Data is written only by the Flow Element that provides it, or the Flow Elements that share it, and only while they process. Once a Flow Element that writes it has finished, put(String, Object), populateFromMap(Map) and every setter built on them fail with an IllegalStateException. Values kept once they have been read, with keepValues(Map), are not writes. Like the Flow Data that holds it, Element Data is not safe to use from several threads at once.

Element Data that can be pooled goes back to its Flow Element's pool when the Flow Data that holds it is closed, and may then be given to another request. Keeping a reference to Element Data after its Flow Data is closed is not supported, and reads do not check for it.
