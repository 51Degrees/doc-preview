tests.test_free_threaded Namespace Reference

Detailed Description

On a free-threaded build of Python, loading the native module turns the GIL back on, with a RuntimeWarning, because the module does not declare that it runs without the GIL.

A change that loaded it with the GIL still off fails here. Each check runs in a new interpreter, as this one may have loaded the module already.
