fiftyone_pipeline_core.flowdata.ElementDataView Class Reference

Detailed Description

The Element Data of a FlowData, keyed by data key, as the list was when the view was taken.

Adds made elsewhere after that are not seen, so a reader part way through always sees a whole list.

Setting a key adds to the FlowData, and this view then shows the list as it is after the add. Element Data is not removed, so del, pop, popitem and clear raise TypeError. copy gives a dict.

Once the FlowData has finished processing the view is read only, so setting a key, update, setdefault and |= raise as a write to the FlowData does.

Iteration gives each key once, in the order the keys were first added. While a Pipeline processes, each Flow Element adds its own in turn, so that is Pipeline order. Element Data added another way, such as before processing, is listed by when it was added.
