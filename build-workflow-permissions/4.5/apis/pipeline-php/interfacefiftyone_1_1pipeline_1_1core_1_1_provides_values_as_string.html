fiftyone\pipeline\core\ProvidesValuesAsString Interface Reference

Detailed Description

Implemented by Element Data that holds its Property values as strings and parses them into the type each Property declares.

It gives the string as the data holds it, beside the parsed value that get() gives. For example, a Boolean Property whose data holds "Unknown" is false through get(), and "Unknown" through getValueAsString().

Not every Element Data offers this, so test for it before using it: 

if ($data instanceof ProvidesValuesAsString) {
    $stored = $data->getValueAsString('javascriptgethighentropyvalues');
}

See "Values stored as strings" in the pipeline specification's features/value-types.md.
