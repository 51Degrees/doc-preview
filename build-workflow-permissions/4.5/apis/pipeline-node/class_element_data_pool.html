ElementDataPool Class Reference

Detailed Description

A bounded pool of Element Data, so a Flow Element reuses instances rather than making one for every request.

An instance goes back to its pool when the Flow Data that holds it is disposed and its processing has finished, unless a cache holds it, as the cache shares it with other requests. Keeping a reference to Element Data after its Flow Data is disposed is not supported, because the pool may give the instance to another request. Nothing checks for that when the Element Data is read.
