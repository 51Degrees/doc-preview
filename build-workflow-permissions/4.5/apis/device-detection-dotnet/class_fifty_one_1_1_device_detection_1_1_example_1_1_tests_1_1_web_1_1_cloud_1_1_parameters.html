FiftyOne.DeviceDetection.Example.Tests.Web.Cloud.Parameters Class Reference

Detailed Description

The cases the Accept-CH tests run against the cloud web examples.

The case with every SetHeader property uses the resource key that LiveCloudKey finds. The single header cases use the licence key in LICENSE_KEY_ENV_VAR alone and ask the cloud for only the properties they need, sent as 'values'. No key is part of a case, so no key appears in a test's name.
