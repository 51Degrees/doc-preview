Detailed Description

The calls this demo makes to the cloud.

It passes the evidence on as it is and reads what the cloud gives back. It never works a level out, because the level is the cloud's to give.

The evidence for a passive call: the visitor's request headers the cloud reads, with their values as they came, and the visitor's address.

Only the cloud's headers are passed on, so headers such as Authorization stay here. The address is set last, so no header can replace it.
