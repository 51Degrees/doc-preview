fiftyone_pipeline_engines.datafile_update_service.DataUpdateException Class Reference

Detailed Description

A data update that failed, which an update from memory raises to its caller.

The message is the one the errors table of the data updates specification gives for the failure, and the error that caused it, if any, is chained as its cause.
