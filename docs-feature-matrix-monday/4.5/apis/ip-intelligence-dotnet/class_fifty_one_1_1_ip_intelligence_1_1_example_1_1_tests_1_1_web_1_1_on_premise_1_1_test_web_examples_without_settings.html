FiftyOne.IpIntelligence.Example.Tests.Web.OnPremise.TestWebExamplesWithoutSettings Class Reference

Detailed Description

Runs each on-premise web example as someone who has just cloned the repository does, with no arguments and none of the settings the other tests are given, and asks it for its page.

So the examples use the free data files that the data repository links, and these tests check that each page is served, shows the properties only the Enterprise data file has as needing it, and links to the contact page.
