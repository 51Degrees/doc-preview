tests.test_onpremiseperformance Namespace Reference

Detailed Description

Runs the on-premise performance example as a person runs it, with python -m and its -d, -u and -j options, on the free Lite data file and a short file of User-Agents so that it takes seconds.

Its work is done under if name == "__main__", in a separate process for each processor, so it runs in a process of its own here.
