fiftyone.pipeline.engines.data.ProvidesValuesAsString Interface Reference

Detailed Description

Implemented by Element Data that holds Property values as strings and parses them into the type each Property declares, so a caller can read the string the data holds as well as the parsed value.

A parsed value cannot always say what the data holds. "Unknown" in a Boolean Property, for example, is parsed to false, which cannot be told apart from a false the data really holds. Test for this interface at run time, and use the typed accessors where it is absent.
