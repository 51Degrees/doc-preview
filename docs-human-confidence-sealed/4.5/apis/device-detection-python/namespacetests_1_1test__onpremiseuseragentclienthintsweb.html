tests.test_onpremiseuseragentclienthintsweb Namespace Reference

Detailed Description

Requests the page of the on-premise User-Agent Client Hints web example, with the headers Chrome sends on its first visit.

The example finds its data file itself, as it does in a fresh clone, so it uses the free Lite file.

The example's configuration shares usage, and usage sharing sends what is queued when the pipeline closes, so requests.post is replaced for as long as the pipeline is open and nothing is sent.
