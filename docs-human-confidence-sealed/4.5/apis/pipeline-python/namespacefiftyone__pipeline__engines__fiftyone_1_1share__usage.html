◆ fiftyone_packages()

fiftyone_packages ( flow_elements)

The name and version of every 51Degrees package in use, sorted by name and each given once.

These are the package that holds the Pipeline, the package that holds each flow element and every 51Degrees package those require. A flow element from no installed package, such as one an application defines, adds none.

@type flow_elements: list

Parameters
flow_elementsthe flow elements of the Pipeline @rtype: list
Returns
: (name, version) pairs, with the name the package is published under
