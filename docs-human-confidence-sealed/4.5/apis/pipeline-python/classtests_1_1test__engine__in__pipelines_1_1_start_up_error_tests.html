tests.test_engine_in_pipelines.StartUpErrorTests Class Reference

Detailed Description

An error the errors table does not name, raised by the update on start-up while a Pipeline is built.

The error reaches the caller, so the Pipeline is never made. resource-cleanup.md says "There MUST be some mechanism to clean up system resources", so closing the engine still stops its data file's checks.
