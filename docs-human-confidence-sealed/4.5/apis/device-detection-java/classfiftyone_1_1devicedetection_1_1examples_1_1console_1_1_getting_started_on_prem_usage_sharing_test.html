Detailed Description

The on-premise getting started console example does not share usage (device-detection-specification/required-examples.md, "Reference implementations inhibit usage sharing for console examples by ensuring the Usage Sharing Element is not added to the Pipeline, but enable it for web examples", and "Every example in which usage sharing is inhibited needs to have a comment saying that in normal operation usage sharing should be enabled by adding a Usage Sharing Element to the Pipeline").

The example builds its Pipeline from its options file with the FiftyOnePipelineBuilder, which adds a Usage Sharing Element unless told not to. The test builds the Pipeline from the same file in the same way, without the engine, which needs a data file, and checks that no Usage Sharing Element is added. Building shares nothing; only processing does.
