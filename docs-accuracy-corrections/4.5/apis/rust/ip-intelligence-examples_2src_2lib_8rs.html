pub const pub fn data_file_properties ( data_file:& Path) -> Result< Vec< String > >

The names of the properties the data file at data_file carries.

This opens a second engine over the same file with the low-memory profile, which leaves the data on disk, and no named properties, and asks it. The pipeline builder does not hand back its engine, and an engine built with named properties lists the names it was given, including any the file lacks.
