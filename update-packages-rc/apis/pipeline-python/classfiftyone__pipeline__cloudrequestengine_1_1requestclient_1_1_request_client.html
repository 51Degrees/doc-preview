fiftyone_pipeline_cloudrequestengine.requestclient.RequestClient Class Reference

Detailed Description

Sends the cloud request engine's requests with the requests library.

A request waits at most its timeout to connect, and at most that long again for each part of the answer, so a cloud service that takes the connection and never answers cannot hold the caller.
