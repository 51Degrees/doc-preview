◆ close()

fiftyone\pipeline\core\Pipeline::close ( )

Close the FlowElements that have a close method, which releases the native resources they hold, unless the autoCloseElements setting is false.

Call it in a finally block once the Pipeline is finished with.

FlowData created by the Pipeline are not closed by it. Close each one as well, because the results it holds keep the engine's data in memory until they are released.

◆ currentDataKey()

fiftyone\pipeline\core\Pipeline::currentDataKey ( string $key)

The Data Key of the FlowElement a deprecated Data Key gives, in any letter case, logging once for each deprecated key that it was used, or the key unchanged when it is not deprecated.

getElement and FlowData::get call it after their own keys, so an old key finds the element and its data.

◆ getElement()

fiftyone\pipeline\core\Pipeline::getElement ( string $key)

Get a FlowElement by its Data Key, compared ignoring case as every string key is, after the exact key.

As in FlowData::get, an element's own Data Key comes before a deprecated Data Key, which is logged once.

Exceptions

Exception if no FlowElement has the key

◆ getEvidenceKeyFilter()

fiftyone\pipeline\core\Pipeline::getEvidenceKeyFilter ( )

The Evidence the Pipeline accepts, being every key that at least one of its FlowElements accepts, in any letter case.

Each element is asked when a key is checked, so the filter follows an element whose accepted Evidence changes, as it does when an engine's data is refreshed.
