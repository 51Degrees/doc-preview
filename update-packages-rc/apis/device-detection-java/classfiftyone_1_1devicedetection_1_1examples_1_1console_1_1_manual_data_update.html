fiftyone.devicedetection.examples.console.ManualDataUpdate Class Reference

Detailed Description

Shows how to make the on-premise device detection engine load a new data file when the application decides to, rather than through an automatic update.

The engine goes on detecting while the file loads, so the application does not need to restart.

In practice a newer data file is copied over the one the engine was built with, for example by a scheduled task, and then refreshData is called. This example has no newer file, so it reloads the file it started with and the results stay the same. refreshData can also be given the contents of a data file held in memory.
