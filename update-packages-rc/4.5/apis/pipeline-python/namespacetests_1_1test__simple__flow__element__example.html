tests.test_simple_flow_element_example Namespace Reference

Detailed Description

The simple flow element example needs no data file, no key and no network,
so it is run here as a person runs it, from the command line, with none of
the _51DEGREES_ environment variables set. What it prints is checked, being
the star signs and the Find out more section it ends with.
