fiftyone_pipeline_engines.missingproperty_service.MissingPropertyService Class Reference

Detailed Description

Raises the error for a property an engine's data does not hold, giving the reason in the order the properties specification sets out, with the missing properties table's message for it.

Property names are compared ignoring case. Engines of a kind override needs_upgrade and engine_reason to add their own steps.
