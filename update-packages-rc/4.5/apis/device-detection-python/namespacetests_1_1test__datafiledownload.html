tests.test_datafiledownload Namespace Reference

Detailed Description

The examples download a free data file that is missing, by running the data repository's script for it.

CI puts the free files in place before the tests run, so nothing else there makes an example download one.

This test makes a folder that holds only what a fresh clone holds before anything is downloaded, being the data repository's download scripts and its link to the free Lite file, which is the only free Device Detection data file. It then looks for the Lite file from that folder, as an example does, and the file must be downloaded and open as the Lite data file.

The link in the folder points at a server on this machine that serves the copy of the Lite file CI has already put in place, so the test runs the script, the download and the engine without depending on the Distributor.
