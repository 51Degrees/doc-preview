fiftyone_devicedetection_cloud.hardwareprofile_cloud.HardwareProfileData Class Reference

Detailed Description

One hardware profile from a profile lookup, read in the way the device data is read.

It is Aspect Data, so a property is read as an attribute, such as profile.hardwarevendor, with get() or with [].

It is also a dict of property name to AspectPropertyValue. Iteration, len and keys() give the names the cloud service gave, and get() takes a default as a dict's get() does. Attribute access, get(), [] and in compare names ignoring letter case. A property whose name is also a dict method, such as keys, is read with get() or [].
