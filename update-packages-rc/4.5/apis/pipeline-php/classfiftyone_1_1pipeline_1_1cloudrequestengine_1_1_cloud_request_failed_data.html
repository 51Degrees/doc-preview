fiftyone\pipeline\cloudrequestengine\CloudRequestFailedData Class Reference

Detailed Description

The Element Data of a cloud engine whose cloud request for the FlowData failed.

It holds no values, and reading any property throws the missing property message with the CloudRequestFailed reason.
