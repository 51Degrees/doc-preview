fiftyone\pipeline\translation\TranslationEngineBuilder Class Reference

Detailed Description

Builds a TranslationEngine in code.

Each method returns the builder, so the calls chain, and build() gives the engine.

A source is a YAML file of "source: translation" lines for one language, named [name].[locale].yml or [name].[locale].yaml, such as countries.fr_FR.yml. The locale in the name is the language the file holds, and all the sources for one language are used together.

◆ addSource()

fiftyone\pipeline\translation\TranslationEngineBuilder::addSource ( string $path,
?string $contents = null )

Adds a source.

Given a path alone, the file is read from disk, and a path with a * or ? wildcard adds every file it matches. A relative path is resolved against the working directory. Given contents too, the first argument is the source's name and nothing is read.

Exceptions

InvalidArgumentException when a source is not named [name].[locale].yml or .yaml, a file cannot be read, or a wildcard matches no file
