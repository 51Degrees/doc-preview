CloudDiscoveryState Class Reference

Detailed Description

A copy of what the Cloud Request Engine's discovery fetched, being the evidence keys the cloud service accepts and its answer listing the accessible properties, which depend only on the keys in use.

An engine given a copy makes no discovery request. The JSON is the form the Java package's CloudDiscoveryState writes.
