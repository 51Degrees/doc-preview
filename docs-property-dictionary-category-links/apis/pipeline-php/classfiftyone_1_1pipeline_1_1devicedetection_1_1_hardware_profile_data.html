fiftyone\pipeline\devicedetection\HardwareProfileData Class Reference

Detailed Description

One profile the hardware profile lookup gives.

It is the Aspect Data the cloud Device Detection engine gives, so a profile is read with get() or as a property, as device results are. It also reads as an array of Property values, by name, in a foreach, with count() and with json_encode(). It cannot be changed.
