fiftyone.pipeline.core.flowelements.ParallelElements Class Reference

Detailed Description

ParallelElements executes it's child FlowElement objects in parallel.

A Pipeline lists a parallel group as one of these, so code that needs every Flow Element in use, such as the usage sharing element, reads the group's members with getFlowElements(). The constructor is package-private, so only the Pipeline builders create one.
