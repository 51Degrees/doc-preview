Detailed Description

Runs the getting started example of the fiftyone_devicedetection package, fiftyone_devicedetection/examples/gettingstarted.py, as it is.

It opens the free Lite data file by a path relative to the working directory, which leads to the cxx submodule from the package's own folder, so it is run from there.

The pipeline builder it uses shares usage, and usage sharing sends what is queued when the pipeline closes, so requests.post is replaced while it runs and nothing is sent.
