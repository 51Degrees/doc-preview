◆ run()

const pub pub fn run ( options:ExampleOptions ) -> Result<()>

Run the cloud options file example.

Reads the options file, puts the resource key into the cloud request engine's build parameters, and builds the pipeline from it with the builders the Device Detection crate registers under their .NET names. It then runs a desktop and a mobile User-Agent through the pipeline, printing IsMobile, HardwareVendor, BrowserName and PlatformName for each with explicit no-value handling.
